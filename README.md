# Аренда спецтехники

Клиентский лендинг и кабинет владельца по скриншотам. Vinext/React, Cloudflare D1 и R2, авторизация Sites. Карточки хранятся на сервере, а не в localStorage.

## Установка и запуск

Из `tehnika-rent/`, Node.js >=22.13, npm и Git:

```sh
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_tearful_infant_terrible.sql
npm run dev -- --hostname 127.0.0.1 --port 5173
```

Открыть http://127.0.0.1:5173/, кабинет — `/owner`. Миграция применяется один раз к новой локальной базе. После изменения схемы: `npm run db:generate`, сборка, применение только новых миграций. Локальные данные отделены от опубликованных.

На локальном dev-сервере кнопка входа использует штатную тестовую учётную запись Sites. Это поведение исключено из production-сборки. `npm start` запускает собранный Worker локально, но не имитирует вход ChatGPT.

## Подготовка под клиента

`src/config.ts`: текст логотипа, компания, город, Telegram username без @ и три тарифа доставки. Серверная настройка email владельца — `src/owner-config.ts`. `null` — стоимость уточняется, `0` — бесплатная доставка. Владелец не редактирует эти настройки. Доступ проверяется сервером по назначенному email проверенной платформой учётной записи.

Карточки: фото JPG/PNG/WebP до 5 МБ, название, описание, положительная цена за час и целая минимальная смена от 1 часа. Сохранение отдельной кнопкой. Скрытая карточка исключается из каталога и калькулятора; её можно восстановить. Удаление требует подтверждения. Изменения доступны посетителям при загрузке страницы, на других устройствах тоже.

Четыре демонстрационные машины добавляются в новую базу однократно атомарным начальным наполнением, отдельно от миграций. Удаление всех карточек не создаёт их повторно. До фотографий используются подписанные локальные SVG-иллюстрации. Владелец меняет фотографии карточек в кабинете. Фон первого экрана меняет разработчик в `src/rental-site.tsx`, убирая подпись заглушки.

Для каждого нового клиента используйте отдельный проект, новый Site ID, отдельную D1 и R2. Не копируйте текущий Site ID, Git, локальные базы, загруженные клиентские файлы и секреты. Настройки текущего проекта находятся в `.openai/hosting.json`.

## Калькулятор и заявки

Аренда = цена за час × целое число часов не меньше минимума. При известном тарифе доставка добавляется к итогу. Иначе показывается стоимость аренды и явное сообщение, что доставка согласуется отдельно. Это предварительный расчёт, не бронирование.

Дата не может быть в прошлом по календарю посетителя. «Скопировать заявку» проверяет форму и копирует машину, адрес, дату, время, часы, зону, стоимость и комментарий. При запрете доступа к буферу появляется текст для ручного копирования. «Открыть Telegram» открывает чат указанного username, сообщение посетитель отправляет самостоятельно. До настройки контакта кнопки показывают уведомление вместо фиктивного адреса.

## Проверки

```sh
node --test tests/rental.test.mjs
node node_modules/typescript/bin/tsc --noEmit
npm run build
```

`tests/browser.mjs` требует работающего локального dev-сервера и Playwright. Задайте `PLAYWRIGHT_MODULE` абсолютным путём к установленному `playwright/index.mjs` либо установите Playwright отдельно для QA. Используется установленный Edge на Windows или Chromium Playwright.

```sh
node tests/browser.mjs
```

Запускать только на изолированной локальной базе с четырьмя исходными машинами: сценарий создаёт тестовую карточку, проверяет и удаляет её. Скриншоты и JSON-отчёт — в игнорируемом `outputs/qa/`. Дополнительные проверки сбоев: `node tests/errors.mjs` с теми же требованиями. Результаты — в `QA.md`.

## Размещение

`npm run build` создаёт Worker в `dist/`. Публикация через Sites сохраняет исходники, применяет миграции и подключает D1/R2. Статическая загрузка одного HTML не поддерживает серверный кабинет.

Демонстрация приватная, только для владельца. У кабинета дополнительная проверка назначенного аккаунта; каждая операция записи проверяет права и Origin. Публичный доступ требует отдельного изменения настроек Sites. Секреты, node_modules, dist, локальные базы и outputs не добавляются в Git. Внешние API-ключи не нужны. Шрифт Manrope хранится локально, лицензия — `public/fonts/OFL.txt`.
