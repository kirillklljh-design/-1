# Работа с проектом

Сайт аренды спецтехники: Vinext/React, Cloudflare D1/R2, авторизация Sites. Страницы и API — app/, компоненты, расчёт и конфигурация клиента — src/, схема — db/, миграции — drizzle/, ресурсы — public/, проверки — tests/.

Точные команды установки, запуска, миграций и сборки — в README.md. Проверки: node --test tests/rental.test.mjs; node node_modules/typescript/bin/tsc --noEmit; npm run build. Браузерные сценарии выполняйте только на изолированной локальной базе.

Владелец управляет исключительно карточками. Не добавляйте ему настройки Telegram, доставки, города и брендинга. Статусов доступности нет. Скрытые машины исключаются из публичного API и калькулятора. Любая запись требует серверной проверки владельца и Origin. Не заменяйте серверное хранение на localStorage.

Не публикуйте секреты, окружение, зависимости, dist/, .wrangler/, .sites-runtime/ и outputs/. Применённые миграции не изменяйте. Для клиентов используйте отдельные Site ID и хранилища. При визуальных изменениях проверяйте 360, 390, 768, 1280, 1440 px. Результаты проверок документируйте в QA.md.
