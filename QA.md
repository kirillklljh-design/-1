# Проверки адаптации к Vercel — 18 октября 2026

## Результаты

- Production-сборка обычного Next.js 16.3.4 завершена успешно, проверка TypeScript без ошибок. Привязок cloudflare:workers и заголовков авторизации Sites в исполняемом коде больше нет.
- 10 тестов Node: формула аренды и доставка, часы и поля карточки, ссылки на фотографии, сигнатуры файлов, Origin с учётом Node/Vercel proxy.
- Политики доступа проверены в движке PostgreSQL через PGlite: публичный посетитель читает только видимые машины; другой авторизованный пользователь не меняет и не удаляет карточки, не загружает фото и не назначает себя владельцем. Владелец видит скрытые карточки и управляет ими. Полное удаление не восстанавливает демонстрационные данные.
- Браузерные проверки клиентской страницы проведены в production-сборке без Supabase: фотографии, расчёт, переходы, копирование, четыре Telegram-кнопки, защита API, состояния без подключения, пустой каталог и ошибка с повторной попыткой.
- 19 сценариев кабинета проверены через локальный HTTP-имитатор Supabase с настоящим Next.js приложением: неверный пароль, отказ пользователю без роли, cookie-вход владельца, создание с прямой загрузкой PNG по подписанному URL, перезагрузка, изменение цены, независимый сеанс, скрытие/восстановление, отмена и подтверждение удаления, Origin, ошибка сохранения, выход.

## Визуальная проверка

Клиентская страница и кабинет проверены на 360, 390, 768, 1280 и 1440 px. На всех десяти сочетаниях ширина документа не превышает ширину окна. Фотографии загружены с ненулевыми размерами. Скриншоты компьютерной и мобильной версий просмотрены.

Все пять фотографий взяты из исходных слайдов: первый экран — из первого скриншота, три машины — из каталога, мини-экскаватор — из кабинета без плашки выбора. SVG ограничивает область отображения встроенного PNG, не перерисовывает и не генерирует изображение. Качество ограничено разрешением исходных фотографий в скриншотах.

Артефакты: outputs/vercel-qa/site-_.png, owner-_.png, public-report.json и owner-report.json. Они игнорируются Git.

## Границы проверки

Пользователь выбрал подготовку кода и инструкции без подключения реального Supabase. Настоящие облачные Auth, Storage и PostgreSQL пока не подключены. Проверки HTTP-имитатора и PostgreSQL RLS не являются подтверждением подключения облачного проекта.

Без двух параметров Supabase сайт показывает исходный каталог, а кабинет закрыт без фиктивного сохранения. После настройки реального проекта нужно пройти контрольный список DEPLOYMENT.md на опубликованном домене.

Telegram владельца и тарифы доставки ещё не заданы. Отправка сообщения вручную в реальный чат не проверялась. Размещение Vercel подтверждается только статусом Ready и реальным выданным адресом, а не успешной локальной сборкой.

Исторические проверки старой версии Sites находятся в истории Git и outputs/qa/; к текущей адаптации относятся результаты outputs/vercel-qa/.
